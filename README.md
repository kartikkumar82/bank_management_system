# Bank Management System (Streamlit App)

A simple **Bank Management System** built using **Python** and **Streamlit**.  
This project allows users to **create accounts, deposit money, withdraw money, check balance, update account details, and close accounts**.  
All account data is stored in a JSON file (`data.json`).

---

##  Features
- ✅ Create a new bank account (with account number & PIN)  
- 💰 Deposit money with validation  
- 💸 Withdraw money with balance check  
- 📊 Balance enquiry with account details  
- ✏️ Update account details (name, email, pin)  
- ❌ Close account with confirmation  
- 🎨 Streamlit web interface for easy usage  

---

## 🛠️ Tech Stack
- **Python** (core logic)  
- **Streamlit** (UI)  
- **JSON** (data storage)  

---

## Install dependencies

pip install -r requirements.txt

## Run Streamlit app

streamlit run app.py
